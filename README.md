# GALACTIC BEDROCK BOT

Базовий бот для Minecraft Bedrock на Node.js та `bedrock-protocol`.

## Можливості

- Підключення до вказаного Bedrock-сервера.
- Вхід через Microsoft/Xbox зі звичайною автентифікацією.
- Повідомлення про підключення, появу у світі, чат і помилки.

## Важливо

Використовуй бота лише на сервері, де маєш дозвіл, і дотримуйся правил сервера. Бот не обходить капчі, черги, блокування чи інші перевірки. Не публікуй токени або вміст папки `profiles`.

## Запуск

Потрібен Node.js 20 або новіший.

1. Скопіюй `.env.example` у файл `.env`.
2. Заповни адресу сервера та порт:
   - `MC_HOST` — адреса сервера;
   - `MC_PORT` — порт Bedrock (часто 19132);
   - `MC_USERNAME` — ім’я профілю.
3. У терміналі виконай:

```bash
npm install
npm start
```

4. Під час першого входу програма може показати інструкцію та одноразовий код Microsoft. Вводь його лише на офіційній сторінці Microsoft.
